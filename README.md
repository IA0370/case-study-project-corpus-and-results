# Guarding the Gate - Project testing corpus and results

## Replication artefacts for a quantitative comparison of a deterministic pre-model proxy (DPP) against LLM-as-a-Judge configurations and purpose-built classifiers for prompt-injection defence.

### Contents

`runner`: The evaluation runner and analysis scripts (18 Python scripts) 
`configs`: Policy profiles for the proxy (the declarative configuration the policy-agility claim rests on) 
`prompts`: The fixed, versioned judge prompts and the prompt manifest 
`data`: The frozen evaluation corpus (18 suites) and the suite manifests with recorded hashes 
`results`: The captured evidence - raw JSONL plus per-suite CSV exports, in three sub-folders 
`csv_tables`: The published result tables as CSVs with headers
